# Генеалогическое древо семьи

Интерактивное веб-приложение для семейного древа: граф, таймлайн, веер, глубокие профили, редактирование сущностей, JSON-бэкапы, IndexedDB для медиа и первый PDF-экспорт.

## Запуск

```bash
npm install
npm run dev
```

## Что уже есть

- React + TypeScript + Vite.
- Роуты `/`, `/person/:id`, `/important-person/:id`.
- Zustand persist для metadata в `localStorage`.
- `StorageAdapter` и Dexie/IndexedDB-адаптер для фото и видео blob.
- Три режима визуализации: Obsidian-style graph, timeline, fan chart.
- Редактирование людей, добавление родителей, супругов, детей, событий и важных людей.
- Поиск по людям через Fuse.js.
- Импорт/экспорт JSON для бэкапов.
- PDF download через `@react-pdf/renderer`.
- Фото-загрузчик и базовый SVG overlay для тегирования людей на фото.
- Тёмная и светлая тема.
