# Design Brief

Primary screen: a dark archival workspace, not a landing page.

Core layout:

- Top toolbar with brand, search, mode switcher, backup/export actions, theme toggle.
- Left history rail with recently opened profiles.
- Main visualization canvas.
- Right inspector with editable selected entity fields and relationship actions.

Visual tokens:

- Background: true charcoal `#1a1a1a`.
- Current generation: warm amber.
- Paternal branch: cool blue.
- Maternal branch: teal.
- Spouse/important people: violet.
- Radius: 8px or smaller.
